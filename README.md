# 迷你商城 — Web 自动化测试项目

用 [Playwright](https://playwright.dev/) 对一个小型电商 Web 应用进行的 **UI 自动化测试 + API 接口测试** 实践项目，覆盖登录、商品、购物车等核心功能，并包含一次完整的「发现缺陷 → 定位 → 修复 → 回归验证」闭环。

## 技术栈
- Playwright（UI 自动化 + API 测试）
- Node.js

## 测试覆盖（共 10 个用例）

### UI 自动化测试（6 个）
- 登录（正常账号成功 / 密码错误提示）
- 商品列表展示（3 个商品）
- 加入购物车（单商品 / 多商品数量正确）

### API 接口测试（4 个）
- 登录接口（正确账号返回 token / 密码错误返回 401）
- 商品列表接口（返回 3 个商品）
- 不存在的接口返回 404

## 如何运行

```bash
npm install
npx playwright test
```

接口测试所需的本地服务会在运行测试时自动启动（见 `playwright.config.js` 的 `webServer` 配置）。

## 发现的缺陷（实战记录）

测试过程中发现并定位了一个高严重度缺陷：

- **缺陷标题**：加入购物车时，价格 ≥100 元的商品无法加入
- **复现步骤**：登录 → 对「显示器（899 元）」点击「加入购物车」
- **预期结果**：购物车数量 +1
- **实际结果**：购物车数量无变化
- **定位过程**：用「加购全部商品、数量应等于商品数」的用例发现数量少了 1 → 缩小范围单独测显示器 → 确认是高价商品被拦截
- **修复**：移除加购逻辑中错误的 `price >= 100` 判断
- **回归验证**：修复后重跑全部用例，10 个用例全部通过

## 项目结构

```
app/index.html        # 被测的迷你商城网页
api-server.js         # 本地接口服务（登录 / 商品接口）
tests/
  shop.spec.js        # UI 自动化测试
  api.spec.js         # API 接口测试
  example.spec.js     # 基础示例测试
playwright.config.js  # Playwright 配置（含自动启动服务）
```
